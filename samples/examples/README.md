# Example sheets of the start view

The web app's start view (`web/fixtures/projects.json`) opens these sheets as uploads. The server looks for
each file by its name in `$STOA_EXAMPLES_DIR`, then in this folder. **They are not in the repository**: the PDFs are public originals; each PNG is a high-resolution render of one page of a public original (any render of that page works: it is then simply a new upload); the scan is ours, made from the Level 00 sheet.
